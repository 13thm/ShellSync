#  视觉与组件设计规范（去 AI 化 · 简约浅色定稿）

> 一句话定位：**像微信/QQ 那样——干净、克制、浅色、系统感，一眼让人觉得"舒服、靠谱"，而不是"花哨、像 AI 套模板"。**
>
> 配套令牌文件：[`doc/styles/tokens.css`](./styles/tokens.css)（工程初始化后直接引入即可使用 `var(--xxx)`）

---

## 一、设计总原则

。因此视觉最高优先级是「**耐看、不干扰工作**」，不是「炫技」。

| 原则 | 含义 | 具体做法 |
|------|------|----------|
| **克制** | 一个主色、少用颜色、少用效果 | 全局只用 1 个主题色（柔和绿），功能色低饱和；静态元素用边框而非阴影 |
| **浅色为主** | 白底 + 极浅冷灰，亮堂通透 | 页面底 `#F7F8FA`，卡片 `#FFFFFF`，文字非纯黑 |
| **系统感** | 像原生系统应用，不像网页模板 | 用系统字体栈、标准控件比例、原生滚动条比例 |
| **留白** | 用间距和字号建立层级，而不是颜色和特效 | 信息密度适中，区块之间靠间距分隔 |
| **去 AI 化** | 避开一眼"AI 味"的套路 | 见下表 |

---

## 二、什么是"AI 化"——必须避开的视觉雷区

下面这些是 AI 生成 UI（v0/Claude/Lovable 默认产物）的典型特征，**本项目一律不用**：

| ❌ 雷区 | 表现 | 本项目对策 |
|--------|------|-----------|
| **蓝紫渐变** | 标题/按钮/背景铺满 `indigo→purple→pink` 渐变 | 全局**纯色**，零渐变；主色单用 |
| **玻璃拟态** | 到处 `backdrop-blur` + 半透明 + 模糊 | **不用玻璃拟态**；浮层用白底 + 弱阴影 |
| **超大圆角** | 卡片 `rounded-3xl`(24px+)、按钮胶囊大圆角 | 统一 6–10px 小圆角 |
| **emoji 当图标** | 🚀⚡✨🎯 当功能图标 | 用**线性 SVG 图标**（统一描边 1.5–2px） |
| **重阴影叠光晕** | 多层彩色阴影、glow 发光 | 仅浮层用极弱单层阴影，常态用边框 |
| **彩色/渐变文字** | 标题做渐变文字、text-gradient | 标题纯黑文字，仅用字重区分 |
| **炫酷进场动画** | 元素逐个淡入上浮、scale 弹跳 | 仅必要的滑入/淡入，快而轻 |
| **满屏卡片网格** | feature 卡片三宫格 + 居中 + 巨大图标 | 列表流为主，卡片仅做信息分组 |
| **暗色科技风** | 黑底霓虹、赛博、终端绿 | **坚持浅色**，不搞暗黑科技感 |
| **渐变描边边框** | gradient border 包卡片 | 单色 1px 边框 |

> **判断标准**：截一张图，如果"一眼像某个 AI 模板"——重做。如果像 macOS 设置 / 微信设置 / 系统原生——对了。

## 三、色彩系统

### 3.1 中性色（占面积 90%，骨架）

浅色应用的核心是**干净的灰阶层次**，不是彩色。

```
文字   #1F2329  ──►  #4E5969  ──►  #8A909A  ──►  #C0C4CC  (主→次→弱→禁用)
底色   #FFFFFF(卡片)  #F7F8FA(页面)  #F2F3F5(hover)  #ECEEF1(active)
边框   #F0F1F3(极淡)  #E3E6EB(常规)  #CDD1D8(强调)
```

- 文字**永远不用纯黑 `#000`**，用 `#1F2329`，更柔和耐看。
- 页面底用 `#F7F8FA`（极浅冷灰），比纯白更通透、不刺眼。
- 分隔线优先用 `#F0F1F3`（淡到几乎看不见），强结构才用 `#E3E6EB`。

### 3.2 主题色（占面积 ≤5%，点睛）

全局**只有一个主色**：`#3BA776`（柔和绿，介于微信绿与中性绿之间，萌但不幼稚）。

- 使用场景**克制**：主按钮、选中态、勾选、链接、小角标。
- 大面积背景用它的**淡背景** `--color-primary-bg`（`#EBF5EF`），不直接铺主色。
- **绝不**用主色做大面积背景或渐变。

### 3.3 功能色（低饱和，仅状态提示）

| 语义 | 色值 | 场景 |
|------|------|------|
| 成功 | `#3BA776` | 与主色一致 |
| 警告 | `#E0A13C` | 暖琥珀（非亮黄）：解压成功前的提示 |
| 危险 | `#E45656` | 柔和红（非正红）：删除、报错、杀进程 |
| 信息 | `#4B8AF0` | 沉静蓝：信息性气泡 |

功能色**只用于状态点、文字、小标签**，不要做大面积背景。

## 四、字体系统

### 4.1 字体栈
```css
--font-family: -apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif;
```
- **用系统字体**，跨端原生感（macOS 萍方 / Windows 雅黑），不引 Google Fonts。
- 代码/JSON/端口结果用等宽：`JetBrains Mono / SF Mono`。

### 4.2 字号（基准 14px）

| Token | 值 | 用途 |
|-------|----|------|
| xs | 12px | 时间戳、极小说明 |
| sm | 13px | 次要文字、表单辅助 |
| **base** | **14px** | **正文基准** |
| md | 15px | 略强调正文 |
| lg | 16px | 卡片标题 |
| xl | 18px | 区块标题 |
| 2xl | 22px | 抽屉/页面主标题 |

> 桌面工具类应用，**14px 正文**是最舒服的，不要动辄 16/18。

### 4.3 字重
- 正文 `400`
- 强调/次标题 `500`
- 标题 `600`
- **不用 700/粗体**，太重显得笨。

## 五、间距与圆角

### 5.1 间距（4 的倍数）
```
4 · 8 · 12 · 16 · 20 · 24 · 32 · 40
```
- 卡片内边距：`16px`
- 列表项内边距：`12px 16px`
- 区块间距：`24px`
- 控件之间：`8–12px`

### 5.2 圆角（统一偏小，避免"大圆角 AI 感"）
- 按钮/输入框/标签：`6px`
- 卡片/列表容器：`8px`
- 大面板：`10px`
- 胶囊：`9999px`（**仅** tag、计数角标）
- **不要 16px+ 大圆角**，会立刻显廉价。

---

## 六、阴影与边框（核心去 AI 化手法）

**铁律：静态元素一律用边框，只有浮层才用阴影。**

| 元素类型 | 处理 |
|----------|------|
| 卡片、列表、输入框（静态） | `1px solid #E3E6EB`，**不加阴影** |
| hover 态 | 边框变深 `#CDD1D8`，或背景 `#F2F3F5` |
| 右键菜单、弹窗、气泡（浮层） | 白底 + `--shadow-md` 弱阴影 |
| 模态/置顶窗口 | `--shadow-lg` |

这样画面的"深度感"来自清晰的边框结构，而不是漂浮的模糊光晕——这正是微信/系统应用的质感来源。

---

## 七、图标

- **线性图标（outline）**，描边 1.5–2px，圆角线帽。
- 统一套件推荐：`lucide-vue-next`（轻量、中性，不花哨）或自绘 SVG。
- 图标颜色跟随文字色（`currentColor`），不用彩色图标。
- 尺寸：功能栏 18–20px，列表前导 16px。
- **严禁用 emoji 当功能图标。**

---

## 八、组件规范（按本项目 UI 表面）

### 8.1 右键菜单（精灵悬浮菜单）
- 白底 + `--shadow-lg` + `radius-md`。
- 菜单项：`12px 16px` 内边距，`14px` 文字，hover 背景 `#F2F3F5`，**无圆角扩散**。
- 项之间用 `1px #F0F1F3` 分隔线（仅在「退出」危险项前加分隔）。
- 危险项（退出）文字用 `--color-danger`，**不加红底**。
- 出现/消失：120ms 淡入 + 轻微 scale(0.98→1)。

### 8.2 右侧功能抽屉
- 宽 `360px`，白底卡片层叠在 `#F7F8FA` 页面底上。
- 顶部 44px 高标题栏：左返回/标题，右关闭，`font-weight-600`，底部 `1px` 边框。
- 滑入：320ms `ease-decelerate`，translateX。
- 内容区滚动条 6px，半透明灰。
- 顶部「常用软件/常用目录」区：每条列表项 = 图标(20px) + 名称 + 路径(灰色小字)，右侧失效则整体置灰 50% 透明度。

### 8.3 离线搜索弹窗
- 宽 `420px`，白底 + `--shadow-md`，出现在精灵下方。
- 顶部输入框：无边框，底部 `1px` 分隔线，`14px` 占位符灰色，聚焦时底部线变主色。
- 结果列表分组：「软件 / 目录 / 工具」小标题（12px 灰），点击 hover 灰底。
- 无结果：居中灰色文字「未找到结果」+ 弱图标。

### 8.4 气泡提示（Toast）
- 单行优先，最多两行，最大宽 `280px`。
- 背景 `#FFFFFF` + `--shadow-md`，**不用纯黑底反白**（黑底气泡 = AI/网页感）。
- 左侧 4px 色条表示类型（绿/橙/红/蓝），文字主色。
- 顶部居中或精灵旁浮起，淡入 + 200ms 上移，自动倒计时消失。

### 8.5 设置窗口
- 左侧分类导航（240px），右侧表单区，**参照 macOS 系统设置 / 微信设置布局**。
- 表单：左标签（`13px` 次色）右控件，控件用开关(Switch)、下拉、滑块。
- 开关：关 = `#E3E6EB` 灰，开 = 主色，无动画过渡感夸张。

### 8.6 工具面板通用（JSON / 端口 / 剪贴板 / 待办 / 番茄钟）
- 顶部标题 + 一行操作按钮（次要按钮线框、主操作主色实心）。
- 内容区白卡 + `1px` 边框。
- 输入/文本框：白底，`1px #E3E6EB` 边框，聚焦边框 `--color-primary` + 外圈淡光。
- 代码区：浅灰底 `#F7F8FA` + 等宽字 + 行号（可选）。
- 结果/列表：用分隔线分行，不用卡片堆叠。

---

## 九、按钮

仅三档，**不要更多**：

| 类型 | 外观 | 用途 |
|------|------|------|
| **主按钮** | 主色实心填充，白字，`radius-sm`，hover 变深 | 每屏最多 1 个：格式化、解压、确认 |
| **次要按钮** | 白底 + `1px #E3E6EB` 边框 + 主色字，hover 灰底 | 常规操作：复制、置顶 |
| **文字按钮** | 无背景无边框，主色字，hover 淡底 | 列表内操作：删除、管理 |

- 尺寸：默认高 32px，内边距 `0 16px`，`14px` 字。
- hover 只改色/底，**不放大、不加阴影**。
- 危险操作用红色文字按钮，不用红色实心（避免误触视觉压迫）。

---

## 十、动效（克制）

- 时长三档：`120ms`（反馈）/ `200ms`（展开）/ `320ms`（抽屉）。
- 缓动统一 `cubic-bezier(0.4,0,0.2,1)`。
- **不做**：弹性回弹、scale 弹跳、逐项淡入瀑布流、彩虹过渡。
- 只为状态变化服务，不为"好看"而动。

---

### 11.4 输入框 `AppInput.vue`

## 十二、自检清单（每次出图对照）

做完一个界面，逐条核对，全部 ✅ 才算合格：

- [ ] 没有渐变（背景/文字/边框）
- [ ] 没有玻璃模糊、没有发光光晕
- [ ] 没有 emoji 当图标
- [ ] 圆角在 6–10px 之间，没有超大圆角
- [ ] 静态元素用边框而非阴影
- [ ] 全局只出现一个主色，且面积小
- [ ] 文字非纯黑、底色非纯黑
- [ ] 字号主要在 13–16px，没有为"显眼"用大号字
- [ ] 动画快而轻，没有弹跳瀑布
- [ ] 整体像系统设置/微信设置，不像 AI 模板

## 十三、落地建议

1. 工程脚手架（electron-vite + Vue3）建好后，第一步把 `tokens.css` 引入渲染进程入口。
2. 把上面的 `AppButton / AppCard / AppListItem / AppInput` 放进 `src/renderer/components/ui/`，作为全站基础组件。
3. 后续抽屉、搜索、设置、各工具面板，**强制只用这些原子 + tokens 变量**，禁止内联写死颜色/圆角，保证全局一致性。
4. 图标统一用 `lucide-vue-next`，避免混入多套风格。
